# InterviewIQ 🎯

An AI-powered mock interview platform that generates personalized interview questions from a user's resume, conducts technical and coding interviews, evaluates responses using LLMs, and provides detailed performance analytics.

🚧 **Status: In Progress**

## Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS
**Backend:** Node.js, Express.js
**AI Layer:** Python, FastAPI, LangChain, Gemini/OpenAI API
**Database:** MongoDB, Redis
**Real-time:** WebSockets
**DevOps:** Docker, GitHub Actions
**Cloud:** AWS

## Features (Planned)

- [ ] Resume parsing & skill extraction
- [ ] AI-generated interview questions
- [ ] Live coding round with code execution
- [ ] AI evaluation & feedback
- [ ] Performance analytics dashboard
- [ ] Interview history & progress tracking
- [ ] JWT authentication
